# Centralized Infrastructure Specification: Swiftly Ecosystem

This specification is designed for a **Centralized Infrastructure Repository** that manages multiple projects. `swiftly-server` is the first application to be onboarded.

## 1. Global Infrastructure Design Pattern
- **IaC Tool**: Terraform (v1.5+)
- **State Management**: Cloudflare R2 (S3-compatible backend)
- **Modularity**: Infrastructure must be modularized by project (e.g., `modules/swiftly-server/`).
- **Standardization**: All resources must follow a tagging convention: `Project`, `Environment`, `ManagedBy: Terraform`.

## 2. Target Application: `swiftly-server`
- **Source Code**: `/Users/qkrgustn/Projects/swiftly/swiftly-server`
- **Tech Stack**: Spring Boot (Java 21, Kotlin 2.1), Cloudflare R2 (Storage)
- **Deployment**: Docker Compose (Single EC2 Node for Free Tier cost-efficiency)

## 3. Resource Requirements (AWS Free Tier)
| Resource | Specification | Notes |
| :--- | :--- | :--- |
| **Region** | `ap-northeast-2` (Seoul) | Minimize latency for local dev |
| **EC2 Instance** | `t3.micro` (or `t2.micro`) | Free Tier Eligible |
| **OS (AMI)** | Amazon Linux 2023 | Optimized for AWS |
| **Disk** | 20GB GP3 | Enough for OS + Docker Images |

## 4. Network Architecture (Security Group)
The infra repo must provision a Security Group with the following ingress rules:
- **Port 22**: Restricted to `Admin_IP` (SSH)
- **Port 80**: Public (HTTP) - Redirect to 8080 or used for Reverse Proxy
- **Port 8080**: Public (App API & Swagger)
- **Internal**: All traffic allowed between resources within the same SG.

## 5. Automated Provisioning (User Data Script)
The Terraform code must include a `user_data` script that executes the following on first boot:
1. Update system packages.
2. Install **Docker** and **Docker Compose**.
3. Enable and start Docker service.
4. Add the default user to the `docker` group.

## 6. CI/CD & Deployment Hand-off
- **IAM Role**: Create a dedicated IAM User/Role for GitHub Actions with `EC2FullAccess` (scoped down later).
- **Deployment Secret**: The infra repo should output the `EC2_PUBLIC_IP` and `SSH_KEY` for use in the app repo's GitHub Actions secrets.
